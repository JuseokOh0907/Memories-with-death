# 004 — 맵 구조와 곡선 처리

2026-11-05 확정.

## 0. 방향 — 이어진 하나의 세계, 파츠로 나눠 확장한다

게임의 재미는 **백트래킹하며 지역을 넓혀 가는 것**과 **캐릭터에 얽힌 이야기를 풀어 가는 것**이다.
따라서 맵은 지도 시스템에 그대로 펼쳐지는 **하나의 연결된 세계**이고,
제작 단위로만 **파츠**(지역 조각)로 나눈다. 새 지역은 파츠를 이어 붙여 확장한다.

- **기각 (2026-11-05): 방을 떼어 놓고 페이드로 순간이동시키는 방식** (Hollow Knight 의 씬 전환).
  지도 위에서 공간이 실제로 이어져 있어야 백트래킹 동선과 지도가 일치한다.
  페이드는 리스폰(사망·낙사 복귀)에만 쓴다.
- 스폰 지점(체크포인트·`SafePoint`)은 파츠 안에 둔다.

## 1. 구조 — 충돌은 하나로 합치고, 그림과 배치는 파츠로 나눈다

```
World                  Rigidbody2D(Static) · CompositeCollider2D(Outlines)   Layer Ground
  Part_<지역>          Grid (1칸 = 1유닛) · 위치는 정수 좌표 · 프리팹
    Solid              Tilemap · TilemapCollider2D(Merge)                     Layer Ground
      Rock_*           Sprite Shape · PolygonCollider2D(Merge) — 막는 곡선
    Hazard             Tilemap · TilemapCollider2D(트리거)
    Background         Tilemap (충돌 없음)
    Rooms
      Room_*           트리거 박스 = 방 범위 = 카메라 경계 = 지도 한 칸. 자식 SafePoint
  Part_<지역> …
```

- **핵심: 파츠마다 충돌을 따로 두지 않는다.** 모든 파츠의 `Solid` 가 `World` 의 Rigidbody2D 아래에 있으므로
  `World` 의 CompositeCollider2D 하나가 **파츠 경계를 넘어 외곽선 하나로 합친다.**
  파츠가 따로 충돌을 가지면 두 파츠가 만나는 바닥에 이음매가 생겨 캡슐이 걸린다.
- **사각형 스프라이트를 이어 붙이지 않는다.** 같은 이유(이음매)로 검증표 "모서리 끼임" 에 걸린다.
- **Composite Geometry Type 은 Outlines.** 외곽선이 이어진 선분 체인으로 만들어져
  미끄러질 때 내부 경계에 걸리지 않는다. Polygons 는 내부를 볼록 조각으로 나눠 조각 경계에 걸릴 수 있다.
- **파츠 위치는 정수 좌표.** 파츠마다 Grid 가 따로라 칸이 어긋나면 바닥 높이가 미세하게 달라진다.
- **파츠는 프리팹으로 저장한다.** 지역 단위로 고치고, 이어 붙여 세계를 늘린다.
  프리팹 편집 모드에서는 `World` 가 없어 충돌이 합쳐 보이지 않는다 — 합쳐진 모습은 씬에서 확인한다.
- 배치는 Tile Palette 로 직접 칠한다. 텍스트·코드 생성은 손으로 설계하는 메트로배니아에 맞지 않는다.
- 틈·턱 크기는 계산하지 않고 칠한 뒤 뛰어 보며 맞춘다 (CLAUDE.md 작업 규칙).

### 지도 시스템 대비

- **`Room` 이 지도의 한 칸이다.** 방 범위가 곧 지도에 그려질 영역이고, 방 ID 는 세계 전체에서 겹치지 않게
  파츠 이름을 앞에 붙인다 (`Forest_Entrance`).
- 방문한 방 기록·지도 UI 는 1주차 범위 밖 (인계 문서 §7 "미니맵과 월드맵 UI 제외").
  `PlayerRoomTracker.RoomChanged` 가 그때 기록을 남길 자리다.

## 2. 방 사이 이동 — 이어서 걷는다

- `Room` (트리거 BoxCollider2D) — 플레이어가 들어오면 `PlayerRoomTracker` 에 알린다.
- `PlayerRoomTracker` (플레이어 루트) — 겹친 방 목록을 든다. 문턱에서 두 방이 겹쳐도
  새로 들어간 방이 현재 방, 현재 방에서 나가면 아직 겹친 방으로. 모든 방 밖이면 마지막 방 유지.
- `CameraFollow` — 현재 방의 범위를 경계로 쓴다. 방이 바뀌면 경계만 바꾸고 이동은 SmoothDamp 에 맡긴다.
  첫 진입은 바로 맞춘다.
- `Room.SafePoint` — 낙사 복귀 위치. 3일차 Hazard 에서 쓴다.

## 3. 곡선 오브젝트

| 분류 | 도구 | 충돌 |
|---|---|---|
| 직선 지형 | Tilemap `Solid` | Composite 외곽선 |
| **막는 곡선** (바위·동굴 벽·아치) | **Sprite Shape** (닫힌 도형), 파츠 `Solid` 의 자식 | PolygonCollider2D, Composite Operation **Merge** |
| 배경 곡선 | Sprite Shape 또는 스프라이트 | 없음 |
| **밟는 곡선** | **만들지 않는다** (사용자 결정) | — |

막는 곡선 규칙:

1. **닫힌 면(PolygonCollider2D) 을 쓴다.** 두께 없는 EdgeCollider2D 는 대시·고속 낙하에서 파고들 수 있다.
2. **충돌선을 그림보다 살짝 안쪽에.** 곡선 모서리에서 "안 닿았는데 막혔다" 를 막는다.
3. **파츠 `Solid` 의 자식으로 넣고 Merge.** `World` 의 Rigidbody2D 아래 충돌이라 Composite 가 타일과 한 외곽선으로 합친다.
   따로 두면 타일과 만나는 곳이 이음매가 된다.
4. **꼭대기에 설 수 있는 오브젝트는 충돌 윗면을 평평하게.** 이동 코드는 45°보다 기운 면을 바닥으로 보지 않고
   마찰이 0 이라 둥근 꼭대기에서는 미끄러진다. 서지 못하게 할 곳이면 둥글게 두고 미끄러짐을 의도로 쓴다.
5. 둥근 천장·비스듬한 벽 밑면은 물리 솔버가 미끄러뜨린다. 천장·벽 감지 기준도 45° 라
   그보다 완만한 면에서 어색하면 플레이 후 조정한다.
