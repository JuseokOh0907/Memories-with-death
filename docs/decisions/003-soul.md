# 003 — 영혼(Soul)

2026-10-27.

## 결정

- 영혼은 **물리 바깥**에서 `Transform` 으로 움직인다. Rigidbody2D·Collider2D 없음 → 플레이어를 밀지 않고 벽을 통과한다.
- **씬 루트**에 둔다. 플레이어 자식이면 위치·좌우 반전을 물려받아 클릭 지점에 머물 수 없다.
- 세 모드: 따라다님(플레이어 뒤, `restOffset` 의 x 는 바라보는 반대쪽) → 이동(좌클릭 지점) → 머묾.
  우클릭은 어느 모드에서든 플레이어 뒤로 **순간이동** 후 따라다님.
- 클릭 입력은 `PlayerInputReader` 를 거친다. UI 입력 차단과 "닫은 뒤 뗄 때까지 무시" 가 한 곳에서 같이 적용된다
  — 닫기 버튼을 누른 클릭이 영혼 이동으로 새지 않는다.
- 마우스 좌클릭은 `Attack` 에서 빼고 `SoulMove` 로 옮겼다.

- **사정거리 = 반경 `maxDistance`(기본 8) + 화면** (2026-10-27)
  - 클릭 목표는 반경 안, 화면 가장자리에서 `screenMargin` 안쪽으로 자른다. **화면 밖으로는 이동할 수 없다**
  - 사정거리를 벗어나면 **리그 오브 레전드 오리아나 구체처럼 즉시 플레이어에 다시 붙는다** (날아오지 않음).
    벗어나는 경우는 플레이어가 멀어지거나 카메라가 움직여 영혼이 화면 밖으로 나갔을 때뿐이다
  - 이탈 판정은 실제 화면 가장자리, 이동 한계는 여백 안쪽 — 그 차이만큼 여유를 둬 경계에서 붙었다 떨어졌다 하지 않는다
  - 처음엔 "날아서 복귀" 로 만들었다가 같은 날 즉시 부착으로 바꿨다

## 아직 정하지 않은 것

- 영혼이 무엇을 하는가 (상호작용 · 공격 · 시야 등). 정해지면 Kinematic + 트리거 충돌체를 다시 붙일지 결정
