# 추운 지옥 팔레트 (후보, 2026-11-06)

23색, 6개 램프(어두운 쪽 → 밝은 쪽). 공통 팔레트로 확정되지 않은 **후보**다 — 확정되면 [`../README.md`](../README.md) §4 를 갱신한다.
파일: [`cold-hell.hex`](cold-hell.hex) (Aseprite·Lospec 에 바로 불러오기), [`cold-hell.json`](cold-hell.json) (램프·이펙트 팔레트, 스크립트용).

## 쓰는 규칙
- **값 대비**: 플레이어·적은 밝은 단계(얼음 4~5, 뼈, 피 3)를 쓰고, 배경은 심연과 얼음 1~2 단계에 머문다. 차가운 색끼리라 값 차이로 구분해야 한다.
- **따뜻한 색은 피 램프뿐**: 위험·피격 신호만 빨강을 쓴다. 장식에 쓰면 신호가 약해진다.
- 망령 불꽃은 pixelfx 의 light 버퍼처럼 **Additive** 머티리얼 레이어로 겹치면 얼음 위에서 빛나 보인다.
- 디더는 같은 램프에서 이웃한 두 단계 경계에만 쓴다 (codixel `P.band`).

## 도구에 넣기
- pixelfx: `--opts '{"palette": ["#15142a","#1f5a5c","#3fa89a","#8fe8c8","#effff4","#ffffff"]}'` (json `fxPalettes.wraithFire`)
- codixel: `P.quantize(buf, 23, { palette })` (hex 목록)
- PixelOE: 색 수를 맞춘 뒤 codixel 로 이 팔레트에 다시 매핑
